# Day 2

## Learned

- Difference between Iterable, Iterator, and Generator
- `iter()` converts an iterable into an iterator
- `next()` retrieves the next value from an iterator
- `StopIteration` indicates that an iterator has no more values
- Generators use `yield` to produce values lazily
- A generator function returns a generator object
- A generator object is an iterator
- Lazy evaluation means values are produced only when needed
- `Iterator[int]` can be used as a precise return type for a generator producing integers
